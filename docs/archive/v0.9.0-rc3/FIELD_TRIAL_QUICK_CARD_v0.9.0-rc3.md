# FIELD TRIAL QUICK CARD v0.9.0-rc3

## 1. 本轮资料

- APP_VERSION：`v0.9.0-rc3`
- 源码包：`GasAxisStudio_Source_v0.9.0-rc3.zip`
- 现场试用资料包：`GasAxisStudio_FieldTrial_v0.9.0-rc3.zip`
- 源码包 SHA256：以 `SHA256SUMS.txt` 为准
- 现场试用资料包 SHA256：以外部 `GasAxisStudio_FieldTrial_v0.9.0-rc3.zip.sha256` 为准

## 2. 本轮边界

- 不改协议。
- 不改命令语义。
- 不放宽安全限制。
- 不改变导出字段。
- 本轮包含监测首屏 UI 收口、测试去重、帮助文档与打包校验更新。

## 3. 现场开始前确认

- 目标设备 ID 是否明确。
- 是否为多设备总线。
- 当前是否允许写命令。
- 是否允许使用 `FFF`。
- 当前主动上传状态是什么。
- 结束后需要恢复到什么设备状态。

## 4. 高风险提醒

- 未确认目标设备时，不执行写命令。
- 未隔离的多设备总线上，不直接测试 `FFF` 写命令。
- 快捷按钮只会预填、定位或跳转，不会直接发送写命令。
- 失败场景结束前必须导出会话包。
- 不混用不同 SHA256 的源码包和资料包。

## 5. 暂停上传后读取

- 不会停止设备测量。
- 只会临时暂停设备主动上传实时数据。
- 读取完成后按原始主动上传状态决定是否恢复。
- 如果恢复失败，优先留证，再根据现场审批决定是否重试或保持关闭。

## 6. 必须留证的文件

- `session package`
- `command_log.csv`
- `parameter_change_journal.csv/json`
- `session_summary.json`
- 原始串口日志
- 截图

## 7. 立即上报条件

- 误写设备
- `FFF` 误触发
- 安全限制失效
- 恢复主动上传失败且无法处置
- 关键状态显示错误
- 长时间采集或导出结果异常
