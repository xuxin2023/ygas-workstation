## 1. 快速上手

1. 选择串口、波特率、目标设备和采集方式。
2. 保持默认会话模式为“实时监测模式”。
3. 点击连接。
4. 如满足安全条件，软件会自动发送 `SETCOMWAY=1` 启动主动上传。
5. 监测页会显示 CO2、H2O、温度、压力和实时曲线。
6. 现场结束前，优先导出会话包留档。

## 2. 监测页主流程

- 默认采集方式为“自动上传 / LISTEN”。
- 默认解析模式为 `AUTO`。
- 默认会话模式为“实时监测模式”。
- 连接成功后，若当前为真实串口、非回放、目标为明确三位设备 ID、非 `FFF`、且未启用严格只读 / 严格只听，软件会自动发送 `SETCOMWAY=1`。
- 监测页保留主按钮 `启动实时流` / `重新启动实时流`，并通过 `诊断` 下拉收纳 `切换解析模式为自动识别`、`读取关键配置`、`打开串口日志`。

### 没有曲线排查卡

先看这 8 项：

1. 是否已连接？
2. `实时流` 是 `可启动 / 启动中 / 已开启 / 启动失败 / 禁止自动广播` 中哪一种？
3. `SETCOMWAY=1` 是否 ACK？
4. `RX` 是否有？
5. `有效帧` 是否有？
6. `解析模式` 是否为 `AUTO`？
7. 目标设备 ID 是否正确？
8. 波特率 / 线缆 / 设备输出 `MODE` 是否正确？

## 3. 连接后为什么会自动启动实时流？

- 软件定位是气体分析仪实时数据读取软件。
- 如果设备当前处于被动模式，单纯打开串口不会自动出现数据和曲线。
- 默认实时监测模式会在连接后发送 `SETCOMWAY=1`，用于启动主动上传。
- `SETCOMWAY=1` 只启动主动上传，不会修改 `MODE`、`FTD`、`SENCO`、`ID` 或系数。
- `FFF` 广播不会自动启动。
- 严格只读 / 严格只听不会发送任何命令。

## 4. 现场试用注意事项

- 实时监测模式下，连接成功后软件会自动向明确目标设备发送 `SETCOMWAY=1`，用于启动主动上传。该动作不会修改 `MODE`、`FTD`、`SENCO`、`ID` 或其他校准参数。若启用严格只读或严格只听模式，软件不会发送任何命令。
- 所有写入类快捷动作仍然只会预填、定位或跳转，不会直接发送。
- “暂停上传后读取”不会停止设备测量，只会临时发送 `SETCOMWAY=0` 暂停主动上传，读取完成后再按原状态决定是否恢复。
- `FFF` 是广播地址，会影响总线上所有响应设备。涉及广播的写入动作必须显式确认。
- 现场结束前，优先导出会话包；最近数据 CSV 仅用于快速查看最近缓存。

## 5. 安全与复核

### 实时监测模式

- 允许连接后自动发送 `SETCOMWAY=1`。
- 其他写入仍需人工确认、权限校验和目标设备一致性校验。

### 严格只听模式

- 不发送任何命令。
- 只监听设备已有主动上传流。

### 工程联调模式

- 保持原有命令卡、安全链、权限等级和复核逻辑。

### 严格只读

- 绝不发送任何命令，包括 `SETCOMWAY=1`。

## 6. 常见任务

### 启动实时监测

1. 在“连接与设备模式”页选择串口、目标设备和采集方式。
2. 连接成功后观察顶部状态与监测页状态提示。
3. 如需要手动重试，使用“启动实时流”。

### 读取关键配置

1. 在监测页点击“读取关键配置”，或到“设备控制”页读取。
2. 读取动作不会放宽只读锁、会话模式或目标设备一致性校验。

### 系数读写与复核

1. 先读取当前值。
2. 再填写目标值。
3. 写入后立即复核。
4. 最后导出会话包。

### 导出与回放

1. 优先导出本次会话包。
2. 如只需快速查看最近缓存，可导出最近数据 CSV。
3. 导入 CSV 后可在“数据导出与回放”页执行回放。

## 7. 为什么没有曲线？

- 现场优先按前面的“没有曲线排查卡”从 `实时流 -> ACK -> RX -> 有效帧 -> 解析模式` 顺序定位。
- 若仍无法定位，再结合串口日志、会话包和设备输出 `MODE` 做进一步排查。

## 8. 页面说明

### 连接与设备模式

- 配置串口、采集方式、解析模式和会话模式。
- 本页支持滚动，适配小屏和系统缩放。

### 监测总览

- 以曲线和 6 张核心 KPI 为主。
- 辅助区默认隐藏，曲线设置默认收起。
- 图表会显示实时流、RX、有效帧和解析模式状态。

### 设备控制

- 用于读取地址、模式、关键配置和常用控制命令。
- 快捷动作只做预填，不会直接发送。

### 系数中心

- 以系数工作区表格为主，底层命令卡按需展开。

### 信号与算法参数

- 用于查看和调整信号链路、算法与滤波相关参数。

### 串口助手

- 专家终端默认隐藏，仅在 `EXPERT + 显式启用` 后可见。
- 原始命令发送仍受安全校验和广播风险控制。

### 数据导出与回放

- 用于导出最近数据 CSV、会话包、诊断包和执行回放。
