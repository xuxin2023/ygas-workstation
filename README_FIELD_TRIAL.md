# GasAxis Studio FieldTrial Readme

本资料包用于 `GasAxis Studio v0.9.0-rc5` 现场试用执行、留证、问题反馈和交付校验。

## 1. 先校验包完整性

- 先核对 FieldTrial 外部 `.sha256` 文件。
- 再核对包内顶层 `SHA256SUMS.txt`。
- 确认 `GasAxisStudio_Source_v0.9.0-rc5.zip` 和所有现场文档与 `SHA256SUMS.txt` 一致。

## 2. 阅读顺序

1. `FIELD_TRIAL_QUICK_CARD_v0.9.0-rc5.md`
2. `FIELD_TRIAL_TEST_PLAN_v0.9.0-rc5.md`
3. `RELEASE_CHECKLIST_v0.9.0-rc5.md`
4. `RC_TRIAGE_RULES.md`

## 3. 现场执行与留证

- 每日记录使用 `FIELD_TRIAL_DAILY_LOG_v0.9.0-rc5.md`
- 过程备注使用 `FIELD_TRIAL_NOTES_v0.9.0-rc5.md`
- 问题登记使用 `FIELD_TRIAL_ISSUE_TEMPLATE_v0.9.0-rc5.md`

## 4. 分发边界

- 对外只分发 `dist/GasAxisStudio_FieldTrial_v0.9.0-rc5.zip`
- 不分发旧版 Source zip
- 不分发工作区压缩包
